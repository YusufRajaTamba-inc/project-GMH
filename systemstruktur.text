BATAS TANGGUNG JAWAB
- UI hanya mengurus tampilan, interaksi, dan pemanggilan API melalui services.
- API menangani autentikasi/otorisasi, validasi, aturan bisnis, dan database.
- Alur di backend: route → controller → service → repository → database.
- Modul-modul berjalan dalam satu aplikasi backend dan dirilis sebagai satu
	kesatuan; pemisahan modul tidak menjadikannya microservices.
- UI dan API berkomunikasi melalui HTTP/JSON dengan kontrak yang terdokumentasi
	(misalnya OpenAPI). UI tidak mengakses database secara langsung.

ALUR REQUEST
Browser → apps/web → HTTP/JSON → apps/api → modul domain → database

CATATAN PENERAPAN
- Jalankan UI dan API sebagai proses terpisah saat development. Simpan alamat API
	dalam environment variable yang sesuai untuk masing-masing environment.
- Produksi dapat menggunakan satu domain melalui reverse proxy atau domain
	terpisah dengan CORS yang dibatasi.
- Simpan rahasia hanya di environment/server; validasi input dan izin akses
	selalu diperiksa di API.
- Tambahkan migrasi database, logging terstruktur, penanganan error konsisten,
	serta pengujian untuk service dan endpoint.
